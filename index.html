IEEE 754 Floating-Point Standard (32-Bit Single Precision)
Converts real numbers into the standard 32-bit format: 1-bit Sign, 8-bit Biased Exponent (bias 127), and 23-bit Mantissa (implicit 1.F).
4-Stage Floating-Point Arithmetic Pipeline
Stage 1: Radix Alignment
Compare exponents; shift mantissa of smaller operand right by |E1 - E2|.
Stage 2: Mantissa Addition
Add or subtract aligned fraction parts depending on operation and sign bits.
Stage 3: Normalization
Shift result mantissa so MSB is 1; adjust exponent accordingly.
Stage 4: Rounding & Check
Round to nearest even; verify no Overflow (E ≥ 255) or Underflow (E ≤ 0).

Branch Instructions & Multiple-Bus Organization
Examines branch target calculation and compares Single-Bus vs Three-Bus CPU internal data paths.
SINGLE-BUS ORGANIZATION
• Only one internal bus line shared by all registers and ALU.
• Sequential operand loading: requires temp register Y and output latch Z.
• ADD R1, R2 takes 3 clock cycles: (1) R2 → Y, (2) R1 + Y → Z, (3) Z → R1.
THREE-BUS ORGANIZATION (BUS A, B, C)
• Bus A and Bus B feed ALU inputs concurrently; Bus C receives output.
• Eliminates temporary registers Y and Z completely.
• ADD R1, R2 executes in 1 single clock cycle!

Case Study: ARM Architecture (ARM5 & ARM7)
Examine ARM7 3-stage pipeline (Fetch, Decode, Execute), 37 physical registers, and conditional execution of instructions.
ARM REGISTER ORGANIZATION
• 37 total registers (31 general 32-bit registers + 6 status registers).
• 16 registers accessible in User Mode (R0 to R15):
- R0 to R12: General Data Registers
- R13 (SP): Stack Pointer
- R14 (LR): Link Register (subroutine return address)
- R15 (PC): Program Counter (PC + 8 in ARM state)
• CPSR: Current Program Status Register (N, Z, C, V flags)
CONDITIONAL EXECUTION (BITS 31..28)
• Every ARM 32-bit instruction contains a 4-bit condition field:
- 0000 (EQ): Equal (Z = 1)
- 0001 (NE): Not Equal (Z = 0)
- 0010 (CS): Carry Set (C = 1)
- 1110 (AL): Always Execute (Default)
Significance: Eliminates forward branch instructions in if/else statements, avoiding pipeline flushes completely!

SYLLABUS UNIT 5
Amdahl's Law Speedup Calculator
Formula: Speedup = 1 / [(1 - P) + (P / N)], where P is the parallelizable fraction and N is the number of processor cores.
Flynn's Classification of Computer Architectures
2x2 taxonomy based on the multiplicity of Instruction Streams and Data Streams.
SISD (Single Instruction, Single Data)
Classical Uniprocessor (Von Neumann)
One instruction stream controls one data stream in serial execution. Examples: Intel 8086, classic uniprocessors.
SIMD (Single Instruction, Multiple Data)
Vector & Array Processors / GPU Shaders
Single instruction broadcast to multiple ALUs operating on array data. Examples: GPUs, Intel AVX, ARM Neon.
MISD (Multiple Instruction, Single Data)
Systolic Arrays & Fault-Tolerant Systems
Multiple instructions execute concurrently on a single shared data stream. Rare; Space Shuttle flight computers.
MIMD (Multiple Instruction, Multiple Data)
Multi-Core CPUs & Distributed Clusters
Multiple autonomous processing cores execute independent instruction streams. Examples: Intel Core i7, AMD Ryzen.
Multi-Core CPU Task Scheduler Simulation
Distributes computational workloads across symmetric processor cores.
ARM Thumb Instruction Set (16-bit Compact Architecture)
A 16-bit re-encoded subset of ARM instructions designed to maximize code density in memory-constrained embedded systems.

Basics of Input/Output (I/O) Operations
Comparison of Programmed I/O (Polling), Interrupt-Driven I/O, and Direct Memory Access (DMA).
PROGRAMMED I/O (POLLING)
• CPU continually reads peripheral status register in a busy-wait loop.
• 100% CPU overhead; wastes clock cycles waiting for slow devices.
• No extra hardware lines needed; simple single-task controller.
INTERRUPT-DRIVEN I/O
• Peripheral asserts Interrupt Request (INTR/IRQ) when ready.
• CPU completes current instruction, saves context on stack, and branches to ISR.
• Efficient CPU utilization; ideal for asynchronous keyboard/network events.
DIRECT MEMORY ACCESS (DMA)
• DMA Controller (DMAC) takes over bus for direct high-speed block transfers.
• CPU initiates transfer with base address & byte count, then is freed completely.
• Modes: Burst mode (continuous bus hold) vs Cycle Stealing.
Memory-Mapped I/O vs. Isolated / Port I/O
Memory-Mapped I/O
Peripheral registers share unified memory address space. Accessed using standard LOAD and STORE instructions. Used in ARM and RISC.
Isolated (Port) I/O
Dedicated separate I/O address space (e.g. 64KB in 8086). Requires special processor instructions (IN and OUT).
